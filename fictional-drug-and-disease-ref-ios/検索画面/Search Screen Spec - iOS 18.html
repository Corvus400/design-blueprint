Search Screen — iOS 18 Design SSOT

検索画面 refactor 仕様 (iOS 18 実装向け)。iPhone は portrait・landscape ともに single-pane で idle 状態にインライン履歴を常駐させ、絞り込み・並び替えは UISheetPresentationController (.medium / .large detents)、主要ナビは UITabBar / SwiftUI TabView を維持。 iPhone landscape は HIG 準拠で portrait と同じ UITabBar (ボトム)・上部 toolbar 構造を保持 — サイドバー rail は iPad 専用パターン。 iPad 3 クラス (portrait / landscape / Split View) は iPadOS 18 の top-aligned tab bar ( TabView { … }.tabViewStyle(.sidebarAdaptable) ) で主要ナビを上部に配置し、 bottom UITabBar とハンドロールの nav rail を併用しない 。検索 / ブックマーク / 閲覧履歴 / 計算ツール 4 アイテム、active = 検索。iPad では top-tab-bar の下に .toolbar + master-pane + utility-pane (履歴 / 絞り込み / 並び替え 常駐) の 2-pane を並べる。 右パネルは詳細プレビューでも CTA でもなく、フィルタを観察しながら結果を反復するための作業領域。 すべての devices × themes × states を 1 ページにまとめ、verification table が最下部で PASS/FAIL を集約する。 絞り込みトリガは navigation bar trailing area の SF Symbol slider.horizontal.3 ボタン ( .appbar-filter-btn ) — 浮く FAB は HIG 違反のため使わない。

03 — Typography type

iOS 18 の Dynamic Type テキストスタイル (.largeTitle … .caption2) にマッピング。Latin / 数値は SF Pro, JP は Hiragino Sans。 ATC / YJ / ICD-10 など半角コードのみ SF Mono を使用。Dynamic Type は xSmall 〜 AX5 (導出サイズ上のスケール 約 0.8× 〜 3.1×) でリニアスケールされ、result row は 3 行構造のまま overflow しないように minimum scale factor を 0.85, numberOfLines = 1 + truncation tail で保護する。

Toolbar action contract (HIG)

絞込ボタンの動作 : iPhone portrait のみ UINavigationBar trailing に slider.horizontal.3 を表示。タップで SwiftUI .sheet { FilterSheet() }.presentationDetents([.medium, .large]) (UIKit present(_, animated:) で UISheetPresentationController + medium / large detents) で modal sheet を提示。 シート内左上 キャンセル (UIBarButtonItem cancel)、右上 完了 または 適用 のいずれか (UIBarButtonItem done を .done style で使用、 HIG Modality 規定どおり既存ファイル現行表記を維持する場合は変更不要)。grabber handle 表示。iPad / iPhone landscape では本ボタン非表示。utility-pane の .utility-filter セクションを inline 編集として使用。

並替ボタンの動作 : iPhone portrait のみ UINavigationBar trailing に arrow.up.arrow.down を表示。タップで SwiftUI Menu { ForEach(SortKey.allCases) { ... } } (UIKit UIBarButtonItem(image:, menu: UIMenu(...)) ) で popover menu を提示。アンカーは toolbar button 自身。iPad / iPhone landscape では本ボタン非表示。 utility-pane の .utility-sort セクションを inline 編集として使用。

重複禁止 : 上記 2 ボタンは utility-pane を持つデバイスでは toolbar に 絶対に表示してはならない (utility-pane と機能重複し、HIG Toolbars の "actions must not duplicate adjacent controls" 規定に反する)。

Flutter SSOT integrity contract (Flutter parity scope)

基本原則 : 本 iOS 18 spec は Flutter SSOT ( /.../検索画面/Search Screen Spec.html ) の構造 (frame matrix / utility-pane sections / drugCard / diseaseCard / appliedChipsStrip / masterContentForState / state list 等) を厳密に踏襲する。Flutter SSOT に 存在しない概念・class・関数を iOS で新規追加することは 禁止 。 例外は Apple HIG または iOS-platform-specific 必須要件 (UITabBar / UINavigationBar / SF Symbols / UISearchBar / Dynamic Type / VoiceOver 等) によるもののみで、各例外は本表に明示すること。

iOS 例外項目 HIG / iOS 必須要件由来 元 Flutter
UITabBar HIG / Tab bars NavigationBar (Material 3)
UINavigationBar HIG / Navigation bars AppBar (Material 3)
.searchable() HIG / Search fields Flutter SearchBar
SF Symbols ( pill.fill 等) HIG / SF Symbols (Apple-distributed icon set) Material Symbols ( medication_outlined 等)
SwiftUI Material ( .regularMaterial / .thinMaterial ) HIG / Materials (iOS 18 nav layer) Material 3 surface tonal elevation
Dynamic Type ramp ( .largeTitle .. .caption2 ) HIG / Typography Material 3 Type scale
.sheet + presentationDetents HIG / Modality Material 3 ModalBottomSheet
SwiftUI Menu / UIMenu popover HIG / Pop-up buttons & Menus Material 3 DropdownMenu / PopupMenu
.regularMaterial shadow approximation (radius 8 / y 2 / opacity 0.06) HIG / Materials (iOS 18 surface elevation hint) Material 3 elevation tokens

禁止項目 — Flutter SSOT に存在せず、HIG にも由来しない iOS-original 拡張は全削除:

  • iPhone-landscape 専用の master-row helper 関数および iOS-original .il-* プレフィックスを持つ全クラス (row-card / brand / meta / code / util / utility / util-head / row / section / chip-row 等)。
  • quick-condition chip block 系クラス (utility-condition-* / cc-* と 対応する日本語ラベル) — 全削除。Flutter SSOT に対応概念なし。
  • 結果カードの device-specific バリエーション (iPhone landscape 固有 / iPad 固有 の row shape 等)。
  • device-specific simplified utility-pane (例: iPhone landscape で history のみ表示する変種)。
  • その他、Flutter SSOT に対応概念がなく、本表「iOS 例外項目」にも記載されていない一切の新規 class / 関数。
