検索画面 refactor 仕様 (iOS 26 実装向け)。iPhone は portrait・landscape ともに single-pane で idle 状態にインライン履歴を常駐させ、絞り込み・並び替えは UISheetPresentationController (.medium / .large detents)、主要ナビは UITabBar / SwiftUI TabView を維持。 iPhone landscape は HIG 準拠で portrait と同じ UITabBar (ボトム)・上部 toolbar 構造を保持 — サイドバー rail は iPad 専用パターン。 iPad 3 クラス (portrait / landscape / Split View) は iPadOS 26 の top-aligned tab bar ( TabView { … }.tabViewStyle(.sidebarAdaptable) ) で主要ナビを上部に配置し、 bottom UITabBar とハンドロールの nav rail を併用しない 。検索 / ブックマーク / 閲覧履歴 / 計算ツール 4 アイテム、active = 検索。iPad では top-tab-bar の下に .toolbar + master-pane + utility-pane (履歴 / 絞り込み / 並び替え 常駐) の 2-pane を並べる。 右パネルは詳細プレビューでも CTA でもなく、フィルタを観察しながら結果を反復するための作業領域。 iOS 26 Liquid Glass をナビゲーションレイヤー (UITabBar / UINavigationBar / top-tab-bar / シートハンドル ・ フッタ) に適用し、選択ピルは Regular Liquid Glass ( .glassEffect(.regular, in: Capsule()) ) でフロートさせる。 すべての devices × themes × states を 1 ページにまとめ、verification table が最下部で PASS/FAIL を集約する。 絞り込みトリガは navigation bar trailing area の SF Symbol slider.horizontal.3 ボタン ( .appbar-filter-btn ) — 浮く FAB は HIG 違反のため使わない。

03 — Typography type

iOS 26 の Dynamic Type テキストスタイル (.largeTitle … .caption2) にマッピング。Latin / 数値は SF Pro, JP は Hiragino Sans。 ATC / YJ / ICD-10 など半角コードのみ SF Mono を使用。Dynamic Type は xSmall 〜 AX5 (導出サイズ上のスケール 約 0.8× 〜 3.1×) でリニアスケールされ、result row は 3 行構造のまま overflow しないように minimum scale factor を 0.85, numberOfLines = 1 + truncation tail で保護する。

05 — Screen mocks full matrix

全 … フレーム。iPhone (portrait + landscape) は 9 + 7 states × 2 themes、3 つの iPad utility-pane device class は 7 states × 2 themes × 3 = 42、加えて各 device class に 1 つの reduce-transparency フォールバックフレーム (= 5)、合計 79。79 フレームは device × theme × state の代表行列であり、SearchTab (医薬品 / 疾患) 軸は component spec の Target contracts と verification で別途固定する。 iPhone は single-pane で idle 状態にインライン履歴を常駐 + UISheetPresentationController (filter / sort)、portrait と landscape どちらも UITabBar を維持。iPad 3 クラスは top-aligned tab bar ( .tabViewStyle(.sidebarAdaptable) ) + .toolbar + 右側 utility-pane の 2-pane。 modal 状態は utility-pane device には存在しない。iPad Split View は 960pt 代表フレームで、 右 utility-pane が 300pt 以上確保されることを inline verification で固定する。 ステージマネージャ (Stage Manager) では ウィンドウ幅が iPad Split View フレームと同等以上の際は 2-pane、下回ると iPhone portrait 同等の single-pane + UISheetPresentationController フォールバックにスイッチさせる。

Toolbar action contract (HIG + Liquid Glass)

絞込ボタンの動作 : iPhone portrait のみ UINavigationBar trailing に slider.horizontal.3 を Liquid Glass automatic group ( .glassEffect(.regular, in: Capsule()) ) で表示。タップで SwiftUI .sheet { FilterSheet() }.presentationDetents([.medium, .large]) で modal sheet を提示。シート内 toolbar + handle は Liquid Glass、body は opaque ( secondarySystemBackground )。 シート左上 キャンセル 、右上 完了 または 適用 のいずれか ( .done style、HIG Modality 規定どおり既存ファイル現行表記を維持)。 Reduce Transparency ON 時は glass 部分も opaque fallback。 iPad / iPhone landscape では本ボタン非表示、 .utility-filter セクションを inline 編集として使用。

並替ボタンの動作 : iPhone portrait のみ UINavigationBar trailing に arrow.up.arrow.down を Liquid Glass automatic group で表示。タップで SwiftUI Menu { ForEach(SortKey.allCases) { ... } } で popover menu を提示。menu は HIG glass-popover。 iPad / iPhone landscape では本ボタン非表示、 .utility-sort セクションを inline 編集として使用。

重複禁止 : 上記 2 ボタンは utility-pane を持つ デバイスでは toolbar に 絶対に表示してはならない (utility-pane と機能重複し、HIG Toolbars の "actions must not duplicate adjacent controls" 規定 + iOS 26 Liquid Glass の automatic group が無意味な背景を作る)。
