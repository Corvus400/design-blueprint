ブックマーク / Bookmarks

Saved drug and disease snapshots rendered with the same shell chrome, tab treatment, result-card visuals, swipe delete, disclaimer ribbon, and documentation format as the browsing-history SSOT.

Data source Local bookmarks table; no API call for list rendering.
Order bookmarkedAt DESC is documented here, never rendered as UI helper text.
Tabs すべて / 医薬品 / 疾患 by id prefix.
Search Local name search over stored snapshot display names.

02 Color tokens

Mocks reuse the browsing-history/AppPalette surface, primary, danger, type-marker, and disclaimer tokens.

03 Typography

AppBar title is the shared AppTabHeader title only; counts and load states live in content chrome.

04 Spacing / radii / elevation

All device frames inherit the browsing-history literal-width pattern. Card radius is 10px; swipe action reveal is 72dp.

05 Screen preview mocks

Frames render at literal pixel width. The chrome is canonical: status bar, title-only AppBar, fixed tabs/search, scrollable result area, disclaimer ribbon, and bottom navigation.

06 State transitions

Every transition maps to a retained §H-N state. Reduce Motion fallback freezes shimmer and jumps swipe reveal to its settled position.

07 Component spec

Bookmark row

Same visual contract as browsing-history/search result cards. Drug rows have image tiles; disease rows do not.

Type tabs

Phone uses a fixed 3-tab bar. Pane layouts place keyword search above the vertical tabs.

Keyword search

Searches stored snapshot display names only. No visible implementation notes and no type-badge search claim.

Swipe delete

72dp single-row destructive reveal. No bulk delete FAB.

Empty state

ブックマークがありません / 医薬品・疾患の詳細画面でブックマークを追加すると、ここに一覧表示されます。

Loading

Shimmer skeleton rows only; no visible loading label.

08 Accessibility

Element Requirement
Header Shared title only: ブックマーク.
Tabs Expose selected state and labels すべて / 医薬品 / 疾患.
Search field Label: ブックマークを名前で検索.
Rows Semantic label combines name, type, saved date, and destination.
Swipe delete Expose equivalent action ブックマークを削除.

09.5 Forbidden failure patterns

  • Counts or loading indicators inside the AppBar.
  • Row cards that diverge from the browsing-history/search result visual contract.
  • Text-only bottom navigation glyphs.
  • Visible implementation notes under the search field.
  • Search copy that claims type-badge matching.
  • Disease rows with drug-style image tiles.
  • Non-shimmer loading labels.
  • History retry or bulk-delete affordances.
