Dynamic Type / Hit target / Semantics

  • Dynamic Type 200% — フィールド高 44 → 56 px、結果 Value 36 → 54 px、セグメント高 44 → 56 px。レイアウトは破綻しない (accessibility-large-text mock 参照)。
  • Hit target ≥ 44 px — すべてのタップ可能要素 (セグメント・履歴行・削除アクション・ボトムナビ) は 44 dp 以上を担保。
  • VoiceOver / TalkBack :
    ・ ツール切替: label="計算ツール選択。BMI 選択中。3 件中 1 件目。", trait=button, hint="左右スワイプで切替"
    ・ 入力フィールド: label="身長 (センチメートル)。範囲 50.0 から 250.0。現在 170.0", trait=textfield
    ・ 計算ボタン: label="計算する", trait=button
    ・ 結果バッジ: label="分類: 普通体重 (BMI 22.5)", trait=staticText
    ・ 履歴行: label="2026 年 5 月 10 日 BMI 22.5 普通体重", customAction="削除", customAction="復元"
    ・ Disclaimer: label="免責: 架空データ・医療判断には使用しないでください", liveRegion=false

Contract

  • Height: 26 dp (24–28 dp 範囲)。スクロールアウトしない (シェル直上にレイヤ配置)。
  • Position: bottom safe-area inset の直上。bottom-nav が存在する画面では bottom-nav の上に追加で重ねる (ribbon は z-index 7、bottom-nav は z-index 6)。
  • Pointer-events: none 。テキストは NotoSansJP 700 / 11 px / letter-spacing 0.04em 。
  • Copy (固定・翻訳禁止): · FICTIONAL DATA - NOT FOR MEDICAL USE · 架空データ・医療判断には使用不可 ·
  • Semantics label (separate from visible text): 免責: 架空データ・医療判断には使用しないでください · liveRegion=false
  • l10n key: detailDisclaimer (visible text のみバインド対象。API レスポンスの disclaimer フィールドは表示には 使わない )。

09.5 Forbidden failure pattern

過去のリリースで発生した SSOT 散逸の失敗事例を文書として残し、本仕様書では 同じ構造を再採用しない ことを明示する。

過去の失敗パターン

Round1 / Round2 / Round3 / Round4 / Round5 / Round6 — split-by-round directories were used on the Search Screen and broke SSOT propagation 。 各ラウンドが独立したディレクトリに別々の token / component / l10n key を保有した結果、 Round 間で BMI バッジ色や履歴行レイアウトが drift し、最終的に Round6 のみが正としてマージされた一方で、 Round1–Round5 の作業はビルド成果物に取り込まれずに失われた。

本デリバラブルの方針

この仕様書 (Calc Tools Spec.html) は その失敗構造を回避し、単一ファイルに全ての成果物を集約する (single-file aggregation) 。 Round 別ディレクトリは作成せず、すべての色トークン・タイポグラフィ・モック・コンポーネント仕様・検証レポートを 1 つの HTML に内包する。 文書中に出現する文字列 Round1 / Round2 / Round3 / Round4 / Round5 は、 この §Forbidden failure pattern の散文中にのみ存在し、ディレクトリ・ファイル・コンポーネント識別子としては 一切使用しない 。 ブランド名 Round6 は --c6-primary セットの命名 (シェルトークン名) としてのみ使用する。
