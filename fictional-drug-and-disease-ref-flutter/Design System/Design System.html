B Hard contract

Read before doing anything. Five non-negotiable rules that bound the entire design surface. Lifted verbatim from SKILL.md .

  1. Locale is ja-JP only

    Never retranslate Japanese chip labels — copy them verbatim from Components.jsx ( DRUG_FILTER_AXES , DISEASE_FILTER_AXES ) or lib/l10n/app_ja.arb . Mixed Japanese + Latin identifiers (ATC, YJ, ICD-10) are allowed. Numerals are half-width.

  2. Disclaimer ribbon is always-on

    Any view with medical content must render <Disclaimer/> at the shell layer above the bottom safe-area inset. Never shorten or remove the ribbon copy. Bind text to l10n key detailDisclaimer .

  3. Two color systems, one app

    Round6 ( #007AFF ) for shell / bottom-nav / segmented control / FAB tints / primary actions. Material 3 Detail ( #1F5BB5 ) for content-dense detail surfaces. Don’t mix.

  4. No emoji, no gradients, no full-bleed photography, no inner shadows, no glow

    Material Symbols Outlined only; FILL=1 for selected. Imagery is restricted to cool placeholder gradients ( #D8E2FF ↘ #F2DAFF ) inside drug-card image rectangles — never as page backgrounds.

  5. Domain-flavored examples are not prescriptions

    The seed says: do NOT design new search/detail/list screens by default. Compose from primitives instead. Mock data is not clinical guidance.

D Content fundamentals

Rules for written content: locale, tone, casing, numerals, emoji policy, and the disclaimer copy bound to detailDisclaimer .

Locale
ja-JP only. Mixed Japanese + Latin code identifiers ( ATC , YJ , ICD-10 ). Numerals are half-width.
Tone
Clinical, terse, third-person. No 「あなた」「君」「お客様」 . Section headers are one or two kanji compounds — 概要 / 用法・用量 / 禁忌 / 相互作用 / 副作用 / 薬物動態 / 関連.
Casing & punctuation
Full-width Japanese punctuation ( 、 。 ・ ) inside narrative text. Half-width inside code identifiers and meta lines ( ATC: C08CA01 , 改訂 2024-08-12 ). Ratios use : (e.g. 1:8 ).
Numerals
Half-width Arabic only. Use mg , mL , μg ; never ㎎ , ㎖ . Time of day in 24-hour 09:00–17:00 . Dates ISO-style 2024-08-12 .
Emoji policy
Never. Material Symbols Outlined only; FILL=1 for selected. We do not draw glyphs by hand.
Disclaimer copy
Bound to l10n key detailDisclaimer : · FICTIONAL DATA - NOT FOR MEDICAL USE · 架空データ・医療判断には使用不可 · . Do not shorten, marquee, or truncate. Any disclaimer field from the API is for logging / audit only — never display it.
Brand wordmark
NotoSansJP 700 / 22 px. No logo, no illustration, no consumer-facing branding.

H Disclaimer ribbon

The highest-priority UX requirement in this system. Always-mounted overlay at the shell layer, above the bottom safe-area inset, non-interactive (pointer-events:none). Bound to l10n key detailDisclaimer .

Live render — light & dark

FICTIONAL DATA - NOT FOR MEDICAL USE 架空データ・医療判断には使用不可
light · bg #1A1C1E · fg #FFFFFF · accent #FFB4AB
FICTIONAL DATA - NOT FOR MEDICAL USE 架空データ・医療判断には使用不可
dark · bg #0D0E13 · fg #FFFFFF · accent #FFB4AB

  1. Placement

    Rendered at the app shell layer so it sits on every view, directly above the bottom safe-area inset (above any bottom-navigation when present). Must not scroll. Modal routes may cover it; ribbon resumes visibility on dismiss.

  2. Height

    24–28 dp (we ship 26 dp). Non-tappable.

  3. Colors

    Light: bg #1A1C1E / fg #FFFFFF / accent #FFB4AB . Dark: bg #0D0E13 / fg #FFFFFF / accent #FFB4AB .

  4. Text

    Single line · FICTIONAL DATA - NOT FOR MEDICAL USE · 架空データ・医療判断には使用不可 · in NotoSansJP 700 / 11 px / letter-spacing 0.04em. The system no longer ships a short form — keep the full l10n copy visible. Do not marquee or truncate.

  5. Accessibility

    Announce as label: "免責: 架空データ・医療判断には使用しないでください" , liveRegion: false .

  6. Source of truth

    Bind visible text to l10n key detailDisclaimer . Any disclaimer field returned by API endpoints is for logging / audit only — never display it.

  7. Rule

    Implement as an always-mounted overlay at the shell layer, not as a per-screen widget. Non-interactive (input-blocking). Single text node styled with NotoSansJP 700 / 11 / 0.04em.

L Do / Don’t

Codifies the prohibition list from the hard contract with paired examples. When in doubt, the rule is: flat, neutral, clinical .

Do Flat surface, hairline border

Cards use a single 0.5 px hairline at rgba(60,60,67,.13) and one card shadow. The surface itself is solid #FFFFFF .

Don’t Multi-stop gradient backgrounds

No gradient fills on pages, cards, or chips. The cool placeholder gradient ( #D8E2FF → #F2DAFF ) is reserved for drug-card image rectangles only.

page bg ← not allowed
Do Material Symbols Outlined

Outlined for unselected; FILL=1 for selected. We do not draw glyphs by hand and do not ship an SVG icon set.

M Implementation guidance

Restated from SKILL.md : how to use this design system depending on whether you are making throwaway visual artifacts or production Flutter code.

If creating visual artifacts (slides, mocks, throwaway prototypes)

  1. Copy the assets out: fonts/ , colors_and_type.css , disclaimer-ribbon.css , ui_kits/flutter_app/Components.jsx .
  2. Create static HTML files for the user to view (this document is one such artifact).
  3. Use Google Fonts CDN ( Noto Sans JP + JetBrains Mono ) or @font-face with the bundled OTFs. Never reference fonts/*.otf by relative path from a single-file artifact.
  4. Reproduce previews inline — never <img src="preview/..."> .
  5. Always render the disclaimer ribbon when mocking a screen with medical content.

If working on production Flutter / Dart code

  1. Copy the design tokens into your theme ( lib/theme/app_palette.dart , detail_color_extension.dart ). Do not paste JSX into the Flutter codebase.
  2. Bind all visible Japanese strings to lib/l10n/app_ja.arb . The app_ja.arb file is the verified mirror of the mock-server Kotlin KDoc and is enforced by test/l10n/drug_filter_alignment_test.dart .
  3. Render the disclaimer via MaterialApp.builder as a shell-layer overlay, not as a per-screen widget.
  4. Implement bottom-nav with selectedIcon (filled) vs icon (outlined). Round6 #007AFF for selection pill tint.
  5. Sort values are snake_case with leading minus: -revised_at , brand_name_kana , atc_code , therapeutic_category_name , name_kana , icd10_chapter .

Internal-contradiction fixes

ID Fix
F1 Bottom-nav uses Round6 primary #007AFF . Detail primary #1F5BB5 is reserved for the Material 3 detail color extension only.
F2 Toggleable footer “active” tokens are --d-primary-container #D8E2FF / --d-on-primary-container #001A41 ; off-state uses --d-surface-c #EDEEF3 . No more ad-hoc hex.
F4 Sort values use snake_case + leading minus: -revised_at , brand_name_kana , atc_code , therapeutic_category_name , name_kana , icd10_chapter .
F5 Bottom-nav uses selectedIcon (filled, FILL=1) vs icon (outlined, FILL=0). Implementations must declare both states per destination.

Font substitution flag

NotoSansJP Regular and Bold are bundled in fonts/ . Other weights (300, 500, 900) are not provided; fall back to the OS Japanese stack defined in --font-jp . JetBrains Mono is referenced for --font-mono but not bundled — install via Google Fonts in production, or accept the OS monospace fallback. → flag: ask the user to provide a JetBrains Mono OTF/TTF if mono codes need pixel-perfect rendering.
