Search Screen — Design SSOT

検索画面の refactor 仕様。iPhone portrait は single-pane のまま idle 状態にインライン履歴を常駐させ、絞り込み・並び替えは bottom-sheet、主要ナビは bottom-nav を維持。 landscape の 3 クラス (iPhone landscape · iPad landscape · iPad Split View) は app shell 全タブ共通で bottom-nav をやめ、左端に icon-only の navigation rail を立てる — 検索 / ブックマーク / 閲覧履歴 / 計算ツール 4 アイテム、ラベルなし、active = 検索。iPhone landscape は 既存の Bookmark / History の横 rail 実装と同系統の left-rail パターン (検索画面専用 railWidth 240) で nav-rail の右隣にコンパクト検索 + 縦並び seg-tabs + 履歴 / 絞り込み / 並び替え (intra-rail スクロール) を積む。iPad の 2 つの landscape クラスは .toolbar を維持しつつ nav-rail の右に master-pane + utility-pane の 2-pane を並べる。右パネル / 内側 rail は詳細プレビューでも CTA でもなく、フィルタを観察しながら結果を反復するための作業領域。intra-rail スクロールは bottom-sheet と違い結果リストを決して隠さない — 「結果常時可視」の不変条件を維持するための設計差分。 すべての devices × themes × states を 1 ページにまとめ、verification table が最下部で PASS/FAIL を集約する。
