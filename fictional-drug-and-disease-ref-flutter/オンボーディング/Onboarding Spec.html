04 — Intro carousel OB-1/7/8/11

左右スワイプの 3 ページ。各ページ = アイコン + タイトル + 本文 (スクリーンショットは用いない)。共通要素 = 右上 Skip・3 点ドットインジケータ・Next、最終ページに「使ってみる」。ページ 1 に架空データ免責。iPhone / iPad で破綻なく表示。

05 — Spotlight tour OB-5/6/12

実 UI 上の shell 常時可視 chrome を 1 つずつハイライト (フォーカス枠) し、各要素に「ここを押すとこうなる」カードを添える。対象は 検索フィールド・主ナビゲーション・「アプリについて」アイコン の 3 点のみ。非アクティブタブ内の widget は対象にしない。向きで主ナビの形態が変わる — portrait = bottom NavigationBar / landscape = NavigationRail。

06 — Re-show entry OB-9

「アプリについて」画面に、既存ライセンス項目と同形の再表示項目を追加。選択で intro カルーセルから再提示し、完了フラグは完了のまま維持。画面の既存機能は変更しない。

07 — Responsive breakpoint OB-10

端末クラスは最短辺の閾値 shortestSide ≥ 600 で phone / tablet を判定する。スライダーで幅を変え、600 を跨ぐとレイアウトが phone ⇄ tablet に切り替わる (live)。
