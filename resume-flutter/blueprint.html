概要

会員数360万人超のEC定期便サービス「Oisix」のAndroid/iOSアプリ開発に従事。Androidアプリの機能開発・保守、および技術基盤改善を担当しました。設計レビュー、採用面接、アクセシビリティ監査を担当しています。

担当領域 · 実績

  • ネイティブ実装 (Swift / Kotlin) から Flutter への段階的移行を 14 ヶ月で完遂。クラッシュフリー率を 99.2% → 99.86% に改善。
  • Riverpod 2.x + Freezed を採用した状態管理レイヤーを設計、ドメインモデル 47 種を型生成で整備。
  • VoiceOver / TalkBack に対応したアクセシビリティガイドラインを社内策定し、新規画面の必須レビュー項目化。
  • GitHub Actions による Web (Pages) + 内部配布 (TestFlight, Firebase App Distribution) の CI/CD を構築。
  • 新卒 3 名・中途 2 名のオンボーディングを実施。設計レビューを週次で運用。

関連プロジェクト

01

あおぞらモニター v3 — Flutter 完全移行

家庭向け空気質モニタリングアプリの基盤刷新。ネイティブ実装からの段階的移行を主導し、CI/CD・状態管理・テスト戦略を整備しました。

02

Web ダッシュボード — Flutter Web

業務担当者向けの監視ダッシュボードを Flutter Web (WASM) でリリース。プラットフォーム特化のキーボード操作・テキストスケール対応を実装。

03

アクセシビリティ監査基盤

`flutter_test` ベースのアクセシビリティ走査 (semantics tree 検証) を組み込み、PR ごとに自動レポート生成。
